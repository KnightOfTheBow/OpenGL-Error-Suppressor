# OpenGL Error Suppressor
A Minecraft NeoForge mod that lets only unique OpenGL errors log exactly once, suppressing all subsequent spam.

_Supports all versions from 1.20.5 up to 26.2._ (Tried and tested.)

You may notice a warning log in your console during startup about the mod "using the deprecated 'lowcodefml' language loader." This is completely harmless and can be safely ignored.
